### Sobre mim

Sou desenvolvedor **backend** com foco em **Python** e estudante de **Engenharia de Computação** na **UNIVASF** (conclusão prevista para dez/2026). Escrevo código profissionalmente desde 2023 e gosto de entender o sistema inteiro, da API em produção até o hardware em que ela roda.

- Hoje sou **estagiário de desenvolvimento de software na [eyeson.ai](https://eyeson.ai)**, trabalhando com Django e MongoDB, da especificação ao deploy
- No **TCC**, estou rodando **inferência de CNNs INT8 num processador RISC-V (NEORV32) com acelerador sistólico 8×8 em FPGA** (DE2-115)
- Gosto de engenharia de software bem feita: **TDD**, **arquitetura hexagonal**, padrões de projeto e CI/CD
- Uso LLMs no dia a dia para acelerar o desenvolvimento, e já coloquei IA no centro de um produto publicado na Play Store
